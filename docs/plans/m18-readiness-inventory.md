## How to read the statuses

- **pass / fail**: a measured value compared with an explicit limit.
- **present / absent**: an identifier was or was not found in product source at that revision. This is a search, not proof of behavior. `absent` does not prove a feature is missing, and `present` does not prove it works.
- **partial**: a passing test that covers only part of the criterion. The limit is written next to it.
- **blocked**: an attempted run that did not complete. The reason and exit code are recorded.
- **measured**: a recorded run, with its command and result.
- **not-measured**: measurable in principle but not run here. The command is in the inventory.
- **unavailable**: needs data, a person or a decision that this repository and session do not have. No value is estimated.
- **not-claimed**: this leaf makes no claim.

## Findings

1. **The accessibility scan did not run on this host.** ACC-01 and ACC-02 are `blocked`. The Vite dev server reported ready after 344 s, then did not answer a request for 580 s. The M12 record ([m12-541](../evidence/m12-541-manual-a11y-certification-2026-10-06.md)) reports its own axe and keyboard run on an earlier main. It does not measure this head.
2. **ADR-0010's client JavaScript table is stale.** It lists 2,350,000 raw bytes, 700 KiB gzip and no file cap. The ceilings in `scripts/client-bundle-budgets.mjs` are 3,112,000 raw bytes, 926 KiB gzip and 162 files. Main measures 3,051,665, 928,997 and 159, within those ceilings. This change does not edit the ADR.
3. **ADR-0010's rebuild figure is not reproduced.** The ADR cites about 7 s for a full rebuild. A cold `bun run --cwd apps/web build` took 192 s at `9fb30c49` and 251 s at `34a3eaad`. Both runs exited 0.
4. **Cost is not measured.** Budget reservation and cost-state identifiers are absent on main (COST-03, COST-04). The only zero-model-call test covers the structural-lead setup path (COST-01, partial). Metering (COST-05) and billing reconciliation (COST-06) are unavailable.
5. **Operations mechanisms are absent on main.** Metric, operator-control, feature-flag, retention-gate and export identifiers are absent. Candidate #1244 adds rollback routing identifiers and a rollback or rollout document path. Candidate #1245 adds export identifiers. Candidate #1243 adds no retention-gate identifier that this probe recognizes.
6. **The runtime latency targets are not approved.** PERF-06 (p95 admission at or below 1 s, scheduling at or below 2 s) is a proposal awaiting FOUNDATIONS approval. No benchmark exists, so nothing is measured.

## Reproduce

```sh
bun install --frozen-lockfile
bunx turbo run build --filter='@adea-ai/web^...'
bun run --cwd apps/web build
bun run --cwd apps/web start:check-bundle | sed -n '2p' > bundle.json   # bundle report, line 2
node scripts/readiness-evidence.mjs check
node scripts/readiness-evidence.mjs measure \
  --main 34a3eaad69b6f2d671fd802bfe21bb629e7609ff \
  --candidate 1236=12b63a689858084bbe1fd9b3a6bd1d606317d054 \
  --bundle bundle.json \
  --recorded docs/evidence/m18-1224-recorded-runs-2026-10-10.json \
  --run-unit
```

Pass one `--candidate <pr>=<sha>` per row in the candidate table. Each SHA must be in the local object store (`git fetch origin <branch>`). The measure command rewrites `docs/plans/m18-readiness-measurements.json`. Its unit runs use the working tree, so run it from the revision you want recorded. The `check` command validates the inventory and exits non-zero on any error.
