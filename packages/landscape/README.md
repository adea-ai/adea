# Landscape catalog

The Home and Work scenes use this shared exterior catalog. The runtime loader
and all reusable outdoor models live here, while the models are copied to
`/assets/models` at app startup.

The catalog includes bushes, palms, shrubs, trees, fences, and the downloaded
seasonal/urban background photos. These assets are not exposed through the room
designer; that catalog is reserved for interior furniture, pots, and plants.
